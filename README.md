#  FonemaViva

### Aplicativo educacional de apoio à comunicação oral

<p align="center">
  <strong>FonemaViva</strong> é uma aplicação educacional desenvolvida para apoiar o treinamento da comunicação oral por meio de exercícios fonéticos e atividades de gesticulação.
</p>

<p align="center">
   Projeto de TCC •  Curso Técnico em Informática •  Campinas — SP •  2026
</p>

---

##  Sobre o projeto

O **FonemaViva** é um aplicativo educacional desenvolvido com o objetivo de oferecer uma ferramenta acessível de apoio ao desenvolvimento da **comunicação oral e da gesticulação**.

A aplicação disponibiliza **exercícios gratuitos de treinamento fonético**, buscando auxiliar diferentes públicos no desenvolvimento e aprimoramento da comunicação.

O projeto foi desenvolvido como **Trabalho de Conclusão de Curso (TCC)** pelos alunos do 3º ano B do Curso Técnico em Informática do **Colégio Técnico Bento Quirino**, em Campinas — SP.

>  **Objetivo:** proporcionar uma ferramenta educacional simples, acessível e interativa para apoiar atividades relacionadas à comunicação oral.

---

##  Funcionalidades

-  Exercícios voltados ao treinamento fonético;
-  Atividades de apoio ao desenvolvimento da comunicação oral;
-  Exercícios relacionados à gesticulação;
-  Conteúdo destinado tanto ao público infantil quanto adulto;
-  Utilização gratuita;
-  Interface acessível diretamente pelo navegador.

##  Como utilizar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/FonemaViva.git
```

### 2. Acesse a pasta do projeto

```bash
cd FonemaViva
```

### 3. Execute a aplicação

Abra o arquivo:

```text
index.html
```

O aplicativo será executado diretamente no navegador.

>  **Observação:** por se tratar de uma aplicação web, não é necessário instalar dependências adicionais para executar a versão básica do projeto.
